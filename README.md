# Job Application Tracker

A responsive job application tracker dashboard built with HTML, CSS, and JavaScript.

live demo : https://job-application-tracker-divyansh.vercel.app

## Features

- Add job applications
- Edit existing applications
- Delete applications
- Store applications using Local Storage
- Search applications by company
- Filter applications by status
- Sort applications by newest or oldest
- Dynamic application statistics
- Application status doughnut chart
- Monthly applications chart
- Responsive dashboard design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage
- Font Awesome

## Project Overview

This project is a frontend job application tracking dashboard that allows users to manage and monitor their job applications.

Users can add application details such as company, job role, location, application status, application date, and notes.

The dashboard dynamically updates application statistics and charts based on the stored applications.

## Application Statuses

The application tracker supports:

- Applied
- Interview
- Offer
- Rejected

## Data Storage

Application data is stored in the browser using JavaScript `localStorage`, so the data remains available after refreshing the page.
